# F03 — Coffeetosh UI

The macOS menu-bar application, onboarding, dashboard, settings, session controls, CLI guide, and visual feedback for the Coffeetosh system.

## What We Build

- Menu-bar popover and dashboard flows.
- Session mode and duration selection.
- Loading, active, stopped, expired, and lid-open confirmation states.
- Settings, About, onboarding, and CLI guide screens.
- Responsive SwiftUI layout, animation, accessibility, and CoffeeTosh branding.
